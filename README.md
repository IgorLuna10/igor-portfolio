# Portfolio

Portfolio is a React application built with Vite and Tailwind CSS. It serves as a personal website to display projects and contact information.

## Structure

- `src/App.jsx`: Component routing.
- `src/components/layout/`: Header and footer elements.
- `src/components/sections/`: Content panels (Home, About, Projects, Contact).
- `src/components/stickers/`: Elements with drag behavior.
- `src/data/projects.js`: Project data array.

## Deployment

Deployable to Netlify using the configuration in `netlify.toml`.
